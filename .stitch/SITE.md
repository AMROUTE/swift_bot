# Swift Bot Stitch Site

## 1. Vision

Swift Bot is a local AI knowledge-base Chatbot dashboard. It helps users upload documents, ask grounded questions, and inspect citation sources returned by the local RAG backend.

## 2. Stitch Project

No Stitch project is connected yet. Stitch MCP tools were unavailable during setup.

When available, create or connect a Stitch project and persist project metadata to `.stitch/metadata.json`.

## 3. Product Scope

- Upload local text documents.
- Show document stats and ingestion state.
- Ask questions against indexed chunks.
- Return grounded answers with citation chips.
- Inspect selected citation source text and score.
