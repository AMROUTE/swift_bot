# Swift Bot 中文操作说明

Swift Bot 是一个本地 AI 知识库 Chatbot。当前版本支持上传文本类文档，后端同步切块入库，然后通过关键词/TF-IDF 检索返回带引用的回答。

## 1. 环境要求

- Node.js：满足 `package.json` 里的版本要求。
- Python：当前项目使用 `Backend/.venv`。
- Docker：用于启动 Postgres + pgvector。
- 浏览器：访问前端页面。

## 2. 安装依赖

在项目根目录执行：

```sh
npm install
Backend/.venv/bin/python -m pip install -r Backend/requirements.txt
```

## 3. 启动数据库

项目使用 Docker 启动 Postgres + pgvector。数据库暴露在本机 `55432` 端口，避免和本机已有 Postgres 的 `5432` 冲突。

```sh
docker compose up -d postgres
```

检查容器状态：

```sh
docker compose ps
```

期望看到 `swift-bot-postgres` 为 `healthy`。

## 4. 启动后端

另开一个终端：

```sh
cd Backend
.venv/bin/uvicorn swift_rag.main:app --host 127.0.0.1 --port 8000 --reload
```

检查后端健康状态：

```sh
curl http://127.0.0.1:8000/health
```

正常结果应包含：

```json
{
  "ok": true,
  "database": {
    "ok": true,
    "error": null
  }
}
```

## 5. 启动前端

再开一个终端，在项目根目录执行：

```sh
npm run dev -- --host 127.0.0.1
```

终端会输出前端地址，通常是：

```txt
http://127.0.0.1:5173/
```

如果 `5173` 被占用，Vite 会自动换端口，按终端显示的地址打开即可。

## 6. 使用流程

1. 打开前端页面。
2. 确认左侧状态显示“后端在线”。
3. 点击“载入示例”，或拖入本地文档。
4. 当前支持格式：
   - `.txt`
   - `.md`
   - `.markdown`
   - `.csv`
   - `.json`
   - `.log`
5. 上传成功后，左侧会显示文档数、片段数、字符数。
6. 在中间输入问题，点击“检索回答”。
7. 查看回答里的引用按钮。
8. 点击引用按钮，右侧会显示原文片段和 score。

## 7. 常用 API

健康检查：

```sh
curl http://127.0.0.1:8000/health
```

查看文档：

```sh
curl http://127.0.0.1:8000/documents
```

上传文档：

```sh
curl -F "files=@README.md" http://127.0.0.1:8000/documents
```

提问：

```sh
curl \
  -H "Content-Type: application/json" \
  -d '{"question":"这个项目怎么启动？"}' \
  http://127.0.0.1:8000/ask
```

清空知识库：

```sh
curl -X DELETE http://127.0.0.1:8000/documents/all
```

## 8. 配置说明

默认数据库连接：

```txt
postgresql+psycopg://aman:Aman2026@127.0.0.1:55432/swift_bot
```

默认配置在：

```txt
.env.example
```

如果需要自定义配置，可以复制：

```sh
cp .env.example .env
```

再修改 `.env`。

前端 API 地址默认：

```txt
http://127.0.0.1:8000
```

如需修改，设置：

```txt
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## 9. 常见问题

### 后端显示 `database unavailable`

先检查数据库：

```sh
docker compose ps
curl http://127.0.0.1:8000/health
```

如果 `database.ok` 是 `false`，重启数据库：

```sh
docker compose up -d postgres
```

### Docker 报 `docker-credential-desktop` 找不到

编辑：

```sh
nano ~/.docker/config.json
```

删除：

```json
"credsStore": "desktop"
```

保存后重试：

```sh
docker compose up -d postgres
```

### 本机已有 Postgres 占用 5432

项目已改用本机 `55432`。不要把后端连到 `5432`。

确认后端连接串应包含：

```txt
127.0.0.1:55432
```

### 修改了数据库账号或密码后仍然失败

Docker volume 会保留旧数据库用户。开发环境可重建：

```sh
docker compose down -v
docker compose up -d postgres
```

注意：这会删除本地容器数据库里的已有文档。

### 上传 PDF/Word/PPT 失败

当前 MVP 不支持这些格式。只支持文本类文件。PDF/Word/PPT 是后续功能。
